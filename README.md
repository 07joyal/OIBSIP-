# Graphic Design Internship - Task 1: Promotional Flyer

## Objective

Design promotional flyers for fictional campaigns while applying visual design principles such as color harmony, typography, hierarchy, branding, and effective call-to-action placement.

## Project Overview

This task contains two promotional flyer designs created using graphic design principles.

### Poster 1 - Ada's Lounge Grand Launch Event

A promotional poster created for the launch of **Ada's Lounge**, a café and networking space designed for women in technology. The poster highlights the launch event, venue details, amenities, and registration information using a clean and elegant visual style.

### Poster 2 - Matcha Happy Hour Campaign

A promotional flyer advertising a **Buy 1 Get 1 Matcha Happy Hour Offer**. The design focuses on product visibility, limited-time promotion, strong typography, and a clear call-to-action to attract customers.

## Design Features Implemented

* Defined color palette for visual consistency
* Clear visual hierarchy (headline, subheadline, body content, CTA)
* Custom graphic elements and illustrations
* High-contrast and readable typography
* Promotional branding and marketing elements
* Social media and print-friendly poster layouts
